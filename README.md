# AI-Driven Threat Detection & Automated Incident Response in Cloud Networks

An AI-powered cybersecurity system that detects malicious network traffic and generates automated incident responses using Machine Learning and the Random Forest algorithm.

## 📌 Project Overview

This project focuses on improving cloud cybersecurity using Artificial Intelligence and Machine Learning techniques.

Traditional intrusion detection systems are rule-based and cannot efficiently detect unknown or evolving cyber threats.

The proposed system uses the Random Forest Machine Learning algorithm to analyze network traffic and classify it as:

- Normal Traffic
- Malicious Traffic

If malicious activity is detected, the system automatically:
- Generates alerts
- Displays threat severity
- Recommends mitigation actions
- Updates the real-time dashboard

## 📂 Dataset Used

### UNSW-NB15 Dataset

The project uses the UNSW-NB15 cybersecurity dataset developed by the University of New South Wales, Australia.

Dataset contains:
- Normal network traffic
- Malicious traffic
- Multiple cyberattack categories

Attack categories include:
- DoS
- Exploits
- Fuzzers
- Reconnaissance
- Worms
- Generic attacks

